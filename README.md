# PineOS-pkg
This is the offical PineOS package manager sure it's a pacman wrapper but with extra features.
Note: There are two versions of pkg, pkg-stable and pkg-edge
"Which is for me?" well pkg-stable is for the all rounder who doesnt want breaking software and pkg-edge is the forked version off pkg-stable but with commits almost every day and while this is useful theres a downside as patching new bugs can cause more bugs.
